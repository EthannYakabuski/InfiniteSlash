# Creature Mixer monsters

The 100 named PNG sheets were created using [Kenney Creature Mixer](https://kenney.itch.io/creature-mixer), with the full **Randomize** command and **Save spritesheet** export at **8x**. Every sheet has four animated 192 x 192 cells, totaling 768 x 192 RGBA pixels. The original exported pixels are preserved.

The separately supplied `creature-sheet (2).png` is also preserved. It is not counted among the 100 new monsters in `data/monsters.json`.

Creature Mixer permits personal, educational and commercial use of its generated creations and artwork, excluding NFT and blockchain projects. Giving credit is appreciated but not mandatory. This permission is distinct from the CC0 licenses bundled with the other Kenney asset packs in this project.

Names, initial combat roles and statistics are recorded in `data/monsters.json` and `docs/MONSTER_ROSTER.md`. The complete visual roster and an actual browser export screenshot are in `output/review`. Run `tools/validate_assets.py` to verify the exported dimensions, transparency, animation, stats, file hashes and unique pixel content.
